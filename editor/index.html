For artists and agents

Use the canvas, or edit the same versioned JSON files with the CLI.

python3 tools/characters.py --json list
python3 tools/characters.py --json get cowboy
python3 tools/characters.py clone cowboy ranger
python3 tools/characters.py --json validate
python3 tools/characters.py build

Updates require the revision returned by get, so an agent cannot silently overwrite unsaved work from another session.

python3 tools/characters.py update ranger \
  --input ranger.json --revision <revision>
